# ДСТУ 8302:2015 у Zotero: посібник

Розширення додає до Zotero два стилі за ДСТУ 8302:2015 і вибір параметрів оформлення для кожного документа.

## Встановлення

1. Завантажте файл `dstu-8302-<версія>.xpi` зі [сторінки випусків](https://github.com/walking-wisely/dstu-8302-zotero/releases/latest).
2. У Zotero відкрийте Tools → Plugins, натисніть на шестірню, оберіть Install Plugin From File і вкажіть завантажений файл.
3. Перезапустіть Zotero.

Працює з Zotero 7, 8, 9 і 10. Окремо встановлювати стилі не треба: розширення додає їх саме.

## Два стилі

- **ДСТУ 8302 — виноски**: посилання в нижніх виносках. Для документів, де джерела наводять унизу сторінки.
- **ДСТУ 8302 — у тексті**: посилання в тексті. Вигляд (повний опис у дужках, номер зі списку, автор, автор і рік) обирають у параметрах.

## Параметри оформлення

Усі параметри показано картками з готовими прикладами, тож обирати треба за виглядом. Є параметри для:

- вигляду посилання в тексті;
- розділового знака між зонами опису (§4.4);
- повторного посилання («Автор і скорочена назва» або «Зазнач. твір»);
- розділового знака перед назвою видання (§4.9.1);
- посилання на статтю лише з відомостями про видання (§4.9);
- посилання на вебсторінку лише з адресою (§5.3.6);
- позначки «Електронний ресурс», серії, видавництва й ISBN (§4.4);
- порядку у списку літератури.

Внизу є блок «Повний приклад», де видно всі посилання та список літератури з поточним вибором.

## Вибір для нового документа

Відкрийте Settings (Налаштування) → ДСТУ 8302. Тут обирають вибір за замовчуванням для виносок і для посилань у тексті. Він діє на нові документи.

## Вибір для одного документа

1. У Word натисніть Add/Edit Citation на вкладці Zotero. Для нового документа Zotero спершу відкриє вікно Document Preferences.
2. У списку стилів оберіть «ДСТУ 8302 — виноски» або «ДСТУ 8302 — у тексті». Під списком з'являться параметри; прокручуйте їх колесом миші.
3. Оберіть потрібні картки й натисніть OK.

Вибір зберігається у файлі Word. Змінити його пізніше можна кнопкою Document Preferences на вкладці Zotero. Зберігати вибір окремо не треба: він записується разом з документом.

## Колеги без розширення

Два стилі додає лише розширення, тож співавторам, які працюють з тим самим документом, його теж треба встановити. Без нього Zotero не знатиме цих стилів, а вибір параметрів буде недоступний.

## Стилі без розширення

Для Pandoc, Overleaf та інших програм зі стилями CSL завантажте `dstu-8302-styles-<версія>.zip` зі сторінки випусків. Усередині 20 готових файлів .csl і короткий опис, як обрати потрібний. У Zotero без розширення такий файл додають через Settings → Cite → кнопка «+». Правила, які CSL не вміє, без розширення виконуються лише частково, наприклад «Там само» з іншим томом чи заголовок для чотирьох і більше авторів.

## Відомі обмеження

- Перевірено в Word на macOS. LibreOffice ще не перевіряли.
- Не можна обрати кількість авторів у заголовку та вибір між загальною кількістю сторінок і сторінкою цитування.
- Якщо в Zotero увімкнено рушій citeproc-rs (прихований параметр `cite.useCiteprocRs`), розширення не працює.
- Якщо в Zotero вимкнено автоматичне оновлення посилань, після зміни параметрів оновіть документ кнопкою Refresh.

Про помилки пишіть на [GitHub](https://github.com/walking-wisely/dstu-8302-zotero/issues).
